Free AI 2.3.0 轻量版安装说明

此安装程序包含两个独立入口，共用一份 Python 标准运行环境和数据位置：
- Free AI：日常聊天、下载与使用能力，普通用户打开这个即可。
- Free AI 训练端：准备教学数据、训练模型、查看训练进步。
训练端可从开始菜单打开；桌面快捷方式可在安装时自行勾选。
它不包含大模型、视觉/语音权重、训练框架或任何人的聊天、经验及训练数据。
也不包含 API 连接配置、访问密钥或个人设置。

两个入口首次打开时都未选择模型，不会自动下载或加载模型。
客户端提供 5 种本地聊天模型，推荐 Qwen3.5-4B；训练端使用独立的 Qwen3-0.6B 入门训练模型。
推荐仅供选择：由你点击下载，下载完成后再选择启用。
已下载模型也需要手动选择使用；具体下载大小以应用内清单为准。
可先选择模型和数据保存位置，默认使用非 C 盘的数据位置。
更长的对话属于运行设置；只有额外模型或功能确实需要文件时才下载。

也可以在“设置 → API 连接”填写 DeepSeek 或兼容服务的地址、密钥和模型名称。
首次安装不会自动选择 API；已有选择可恢复，但启动不会发起网络请求。连接测试读取模型列表，不生成回答，也不查询账户余额。
选择 API 聊天后，输入和当前对话内容会发送到你填写的服务；经验库默认不发送，需另行启用。
当前 API 接入仅处理文字，不上传图片；本地计算、JSON 和 CSV 工具仍不联网。
密钥可只在本次运行中使用，或交由 Windows 当前用户保护后保存。换电脑或账户后请重新填写。
没有使用真实用户密钥验证付费服务；服务可用性、余额与收费以服务提供方为准。

内置 10 项技能，无需另外安装技能包：
- 日常对话、文字润色、中英翻译、内容摘要、代码检查、学习辅导、任务拆分：可使用本地聊天模型或已配置并启用的 API；API 方式无需下载模型。
- 算式计算、JSON 检查、CSV 表格统计：本地工具，无需模型，也不会联网。
选择技能不会训练模型参数。工具只验证执行或格式，不保证材料中的事实正确。
CSV 只读取你明确选择的本地文件；模型或文字指令不能替你选择文件。
训练端的 AI 经验总结使用客户端已选中的本地模型或已保存的 API；手动核实经验不需要模型。
API 总结仅在主动点击时发送相关经验材料。临时密钥不能跨进程共享，训练端需要本机加密保存的密钥。
真正的模型参数训练仍在本机使用独立 0.6B 模型，不会因选择 API 而上传训练数据。

升级到已有安装位置时保留用户数据；卸载只移除安装程序部署的文件。
旧版大型运行环境和模型不会被自动删除，以免影响你已有的训练成果。
确认不再需要时，请在了解内容后自行清理旧文件。

Python 及运行库的许可证随程序保留在 runtime/python 中。
下载的第三方模型和运行组件遵循其各自许可证。
