Free AI 2.3.1 安装说明

包含日常客户端 Free AI 和独立训练端 Free AI Trainer，共用基础运行文件。
默认安装到 D:\FreeAI，应用与数据使用非 C 盘。训练端桌面快捷方式可自行勾选。

接下来可以选择模型保存位置：
- 模型放在 FreeAI 里面（推荐）：保存在安装目录下的 models 文件夹。
- 取消勾选：选择另一非 C 盘的本地文件夹。
升级会保留已有位置，除非你明确改选。改变位置只影响以后查找和下载，不自动搬动或删除原模型。
模型位置保存在 model-location.txt，不覆盖聊天与经验的数据设置。

安装包不包含模型、用户数据、API 配置或密钥。首次启动不下载或加载模型，不主动请求 API。
可按需选择 5 种本地聊天模型，或填写自己的 DeepSeek / 兼容 API 连接。
内置 10 项技能，算式计算、JSON 检查和 CSV 统计无需模型。
联网 API 会把当前对话发送至所填服务。模型列表连接测试不代表生成成功或账户余额充足。
密钥可仅本次使用，或使用 Windows 当前用户保护机制保存；换电脑或账户需重新填写。
参数训练仍在本机使用独立 0.6B 模型。AI 经验总结仅在主动点击时执行。

升级和卸载不会递归删除模型目录、聊天、经验或训练成果。
给别人使用时分享安装包，不要把个人数据或 API 配置一起分发。
Python 运行库许可保存在 runtime/python/LICENSE.txt。各可下载模型和组件采用各自许可。
