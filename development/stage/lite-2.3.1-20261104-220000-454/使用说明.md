# Free AI 2.3.1 使用说明

现在有两个独立入口：**Free AI** 用来聊天和使用能力；**Free AI Trainer** 用来准备资料、训练、检查结果和改进经验。它们共用运行环境和 D 盘数据，安装时可以分别创建快捷方式。普通使用者只打开 Free AI 即可。

客户端首页集中处理对话。输入框旁可分别选择**模型**和**技能**；点击 **+** 可添加资料、图片、录音、选择 CSV 文件或使用画图。输入框旁的 **···** 可复制、保存、朗读和纠正回答。Enter 发送，Shift + Enter 换行。“能力中心”分为**聊天模型、技能、扩展能力**三部分，其他设置在左下角。

训练端按“准备资料 → 开始训练 → 查看结果”操作，较专业的设置默认折叠。训练记录中可比较新题目的训练前后回答，不能只凭训练数字下降判断 AI 更聪明。训练端保留经验核实和纠错。

同一台电脑的本地推理和训练会互相检查占用。开始训练前，在客户端设置中“释放模型”，或关闭客户端；本地训练进行中，需要使用同一计算资源的操作会提示等待。训练的停止在安全保存点生效，不要反复点击开始。

Free AI 是原生 Windows 应用，不需要打开网页，也不需要自己安装 Python。轻量安装包只装界面、内置技能和基础运行文件。本地工具可直接离线使用；聊天可选择下载本地模型后离线运行，也可手动连接在线 API 服务，无需下载它的模型。API 接入没有增加额外运行库。

安装后双击桌面或开始菜单里的“Free AI”，点击“下载模型或连接 API”。首次打开没有选中任何模型，也不会自动下载或加载。选择本地运行时，能力中心推荐 Qwen3.5 4B 的压缩文字模型，约 2.74 GB，加基础运行组件约 24 MB；下载完成后点击“使用”即可聊天，已下载过的文件可以直接复用。选择 API 则先填写并启用连接，无需下载聊天模型。安装包不含模型大文件，也不含任何人的对话、API 配置或训练成果。

目前有 5 种本地聊天模型可选，全部按需下载，不会一次全部安装。每项的下载大小、来源和许可在能力中心显示：

| 模型 | 适合用途 |
| --- | --- |
| Qwen3.5 4B | 推荐用于中文聊天、写作和代码问答。默认仅下载文字部分。 |
| Qwen3 0.6B | 体积较小，适合简单问答和初次体验，复杂任务能力有限。 |
| DeepSeek R1 1.5B（蒸馏） | 较小的推理模型，回答可能较慢。 |
| DeepSeek R1 7B（蒸馏） | 更大的推理模型，所需空间和运行内存更多。 |
| Qwen2.5 Coder 1.5B | 代码解释、补全和修改建议；生成的代码仍需自行检查。 |

这里的两个 DeepSeek 选项均为基于 Qwen 的小型蒸馏版，不是 671B 原版。聊天用的 Qwen3 0.6B 压缩文件与训练端的独立训练模型格式不同，不能互相替代。切换聊天模型不等于重新训练，也不会把旧模型的训练参数套用到新模型。

使用在线模型时，打开**设置 → API 连接**。连接预设与密钥都由你选择和填写；全新安装首次启动不会自动选中 API，也不会发起连接。已经明确选择 API 的用户，重启后会恢复该选择，但仍需主动发送消息或点击测试才联网。应用不从系统环境变量读取 API 密钥。

1. 选择 DeepSeek 预设，或填写兼容 Chat Completions 格式的自定义服务。
2. 填写服务的基础地址、API 密钥和模型名称。密钥只需填在应用设置里，不要发到聊天窗口。
3. 选择是否记住密钥，保存设置；需要确认连接时，手动点击连接测试。
4. 明确选择 API 作为本次聊天方式，再输入消息发送。保存配置和连接测试不会自动替你生成回答。

自定义服务需支持 Chat Completions 格式。远程地址使用 HTTPS；本机的 localhost 或回环地址可以使用 HTTP。服务地址应为接口根地址，若提供方要求 `/v1` 等前缀，请保留该前缀。

DeepSeek 预设的基础地址为 `https://api.deepseek.com`，默认模型名为 `deepseek-flash`，也可选择 `deepseek-v4-pro`。这是截至 2026-11-04 核对的官方名称，服务以后可能调整。在线官方模型与上述本地小型蒸馏模型是不同选项。[DeepSeek 官方接入说明](https://api-docs.deepseek.com/)

“连接测试”只请求服务的模型列表（`GET /models`）。成功表示列表接口可以访问，并不证明聊天生成成功，也不代表账户有余额。发送聊天使用另一个接口（`POST /chat/completions`），可以逐段显示回答。某些自定义服务没有模型列表接口，即使聊天可用，列表测试也可能失败。[模型列表接口](https://api-docs.deepseek.com/api/list-models/)、[聊天接口](https://api-docs.deepseek.com/api/create-chat-completion/)

本次没有使用真实用户密钥验证付费服务。实际服务可用性、额度和费用以你填写的服务提供方为准；本地模拟接口的测试结果不能代替真实账户验证。

选择 API 聊天后，你的本次输入和当前对话内容会发送到所填写的服务。经验库默认不随请求发送，需另外明确启用；你主动粘贴到输入框或已经出现在当前对话中的资料属于本次对话内容。API 连接目前只处理文字，不上传图片。算式计算、JSON 检查和 CSV 统计仍由本机执行，不会因你配置了 API 就联网。

选择“记住密钥”时，Windows 使用当前登录用户的保护机制（DPAPI）加密保存密钥；公开连接配置和加密内容位于数据目录的 `api_settings.json`。选择不记住时，密钥仅保留在本次运行的内存中，退出后需重新填写，公开连接配置仍可保存。换电脑或 Windows 账户后请重新填写密钥。此配置文件和临时保存文件不会进入分发安装包。

内置 10 项技能，可从输入框旁的技能菜单切换，也可在“能力中心 → 技能”查看说明。你选过的技能会被记住；选择技能本身不会开始执行。

| 技能 | 如何使用 |
| --- | --- |
| 日常对话、文字润色、中英翻译、内容摘要、代码检查、学习辅导、任务拆分 | 选择本地聊天模型，或配置并启用 API，再输入需求或资料发送。API 方式无需下载模型。这 7 项为模型提供不同的任务说明，属于使用方式，不是模型参数训练。 |
| 算式计算 | 无需模型，输入数字、括号与 `+ - * / // %`；不执行代码。 |
| JSON 检查 | 无需模型，粘贴 JSON，检查语法、提示错误行列并整理缩进。最多 10 万字符、64 层嵌套；重复字段或无法无损整理的数值会提示修正。 |
| 表格统计 | 无需模型，从 **+ → 选择 CSV 文件做统计** 明确选择本地文件，再发送。首行为列名、逗号分隔，支持 UTF-8 和 GB18030，最多 2 MiB、1 万行数据、128 列。 |

表格统计逐列显示空白数、有限数值个数、最小值、最大值和均值；文字与 NaN、无穷大等非有限数会分别说明，不混入数值统计。文件不会被修改，结果可通过原有“保存回答”功能保存。模型型技能只提供任务说明，不会检索网页、运行代码或验证事实；选择 API 时会按上述规则发送聊天内容。本地工具完成也只代表算式、格式或统计检查完成，不代表材料中的事实正确。

原有“工具任务：计算 / 训练摘要”仍在 **+** 菜单中，用于受约束的模型工具实验；选择内置技能会退出该模式。它不会替你任意执行命令或操作第三方应用。

明确选过的本地模型会被记住，但重启应用仍不加载权重，发出第一条消息时才开始加载。设置中的“释放模型”释放当前占用，保留选择；“停用模型”同时取消选择，两者都不删除已下载文件或对话。

建议先留出 8 GB 磁盘空间。4060 用户可在“能力中心”下载“显卡加速”，约 671 MB，之后由程序自动使用；不安装也可使用处理器，速度会慢。普通聊天不需要庞大的训练工具。

“能力中心”支持显示大小、下载进度、暂停、继续、校验和移除。只在你点击下载后获取文件。支持看图、WAV 录音转文字、画图、显卡加速和独立入门训练模型等选项。看图会复用已下载的文字模型；画图目前使用 CPU，512×512，可能较慢。录音只支持 WAV 文件，不包含实时麦克风。朗读使用 Windows 已安装的语音。

“本次能记住的内容”有 4K、16K、32K 三档。这里调整一次回答能读取的文字量，无需再下载模型，但更长会增加内存占用。超过上限时会先舍弃最早的完整对话，并提示；本次新输入过长会报错，不会悄悄截断资料。左侧“新的对话”可分开管理多份任务，聊天自动保存在本机。已停止的部分回答也会保留。

训练端同样首次不选择、不加载模型。准备卡推荐独立的 Qwen3-0.6B 入门训练模型（约 1.5 GB），下载后还需点击“使用这个模型”；已有旧文件时无需重新下载。训练工具按需安装（数 GB，至少预留 12 GB）。选择模型不会开始训练，点击“开始训练”才加载并学习。0.6B 的旧学习成果不会套用到不同的 4B 模型，本次没有训练新参数。

API 聊天不会把本地训练改成云端训练，也不会上传训练数据。训练流程仍使用独立的本地 0.6B 模型。

训练端的“经验改进”保留实践记录、核实、查找和复用流程。经验记录不会自动改变模型参数，手动核实经验无需模型。如需 AI 帮忙总结，可使用客户端已选择的本地聊天模型，也可使用客户端已经保存并选中的 API 连接。

使用 API 总结时，只有你主动点击经验总结才会把相关经验材料发送给所填服务；这与普通 API 聊天默认不附带经验库是两项独立操作。训练端是独立进程，不能取得客户端仅在本次内存保存的密钥。若提示密钥不可用，请回客户端设置勾选“在本机加密保存密钥”，保存后再在训练端操作；不愿保存密钥时可继续手工核实经验或使用本地模型。API 总结只生成建议，不会开始参数训练。

程序默认安装在 `D:\FreeAI`。聊天、经验和训练成果保存在其中的 `portable_data`；模型、扩展和对应下载缓存默认在 `FreeAI\models`。安装时可以另选模型位置，不另选就留在 FreeAI 内；这只决定文件保存位置，不会自动下载模型。升级时会保留已有模型位置，旧下载也可继续使用。客户端“设置 → 文件放在哪里”和能力中心会显示真实位置。改变记录位置不改变模型位置；迁移时请一并带上使用过的文件夹。安装包可以单独放在 FreeAI 外。按此前约定，程序及默认数据使用非 C 盘；只有 C 盘的电脑需要先准备其他数据盘。

升级不会主动删除已有数据、旧模型和训练环境，因此旧安装目录不会自动变小；轻量体积适用于全新安装。卸载保留额外下载和个人记录。如需移除某种能力，请在能力中心操作；聊天和经验会保留。

需要检查应用时，可运行 `Free AI.exe --self-test` 或 `Free AI Trainer.exe --self-test`。它们使用临时数据验证各自界面，不会修改日常记录。能力中心每项能力的“管理”菜单可核验下载文件。

给别人使用时，请分享已生成的 `FreeAI-Setup-版本号.exe`，对方自行选择模型、能力或填写自己的 API 连接。迁移自己的资料时，关闭两个应用，复制整个安装目录和“设置”显示的数据目录；自定义绝对路径需要在新电脑重新选择，API 密钥需要重新填写。不要只复制快捷方式或单个 EXE，也不要把个人数据当作安装包发给别人。显卡加速仍需要新电脑有兼容的 NVIDIA 驱动。

模型、引擎的来源、固定版本、文件大小和 SHA-256 见 `capability_catalog.json`。不同模型与量化发布者可能采用不同许可说明，下载前请查看对应条目；完整许可参见清单中的官方来源。
